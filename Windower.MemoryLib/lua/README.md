## About

NoDelay is an addon for [Windower 4](http://www.windower.net), which enables:
- Instant feedback of bid when using the auction house
- Removal of character locking when disengaging in combat

The same functionality can be found in other addons for [Ashita v3](https://www.ashitaxi.com):
- InstantAH
- NoLock

## Setup

- 1) Copy the NoDelay folder into your Windower addons folder.
